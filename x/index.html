handsofflinks

$99 one time

Builds backlinks by publishing real assets to public developer platforms, without sending an outreach email to anyone.

toolsthatrank

$99 one time

A programmatic SEO pipeline that will not let the model type a number. Code fetches each value, recomputes it, then re-fetches the citation to check it still says what was claimed.

You get the full source, unlimited sites and niches with no per site fee, fourteen anti fabrication layers, and nine model providers behind one environment variable. You pay your own inference. Fourteen day refund window.

A run wanted grams per cup for butter, could not source the value, and held it. The page shipped without that unit rather than with a plausible one. Nothing publishes at all until a human clears the last stage.

See toolsthatrank, $99

aiwebsitepipeline

$199 one time

The build architecture underneath the other two, written down. Thirteen layer contracts and 395 gates that decide whether a run is allowed to keep going.

You get one repository with the full source, a seventeen command CLI, and the documents that specify every gate and every threshold. Python, standard library only. Fourteen day refund window on whether the software does what the page says.

Buy this if you have written an orchestrator and hit the problem where a layer passes because a flag was missing rather than false. It is the specification you are paying for. There are no buyers yet, so there are no reviews and no case studies to show you.

See aiwebsitepipeline, $199
