Before you buy

Which one should I buy first?

Start from the problem, not the price. If you want links and will not email anyone, handsofflinks. If a model has invented a statistic on a page you shipped, toolsthatrank. If you are about to start site number four and dread re-making the same fifty decisions, aiwebsitepipeline. If your agentic dev runs have no gates and no budget ceiling, ml0x Pipeline. If a training run just failed and you are debugging rather than learning, Training Run Triage. If two of those describe you, buy the cheaper one and see whether you actually use it.

Can I buy more than one?

Yes, and there is no bundle price. I would rather not dress a discount up as a reason to buy something you have no use for. Each product has its own checkout on its own page, so two purchases means paying twice, and each refund window runs from its own purchase date. Nothing about one purchase changes the terms of another.

What do I need to run these?

Your own machine, and for toolsthatrank and ml0x Pipeline your own API keys, because you pay your own inference. handsofflinks is macOS only and needs Node 18 or newer. aiwebsitepipeline is Python with the standard library only. Training Run Triage needs Python 3.9 or newer, with torch only where it cannot be avoided. ml0x Pipeline is bash and Python. None of the five is a hosted service and none of them phones home.

What happens if it does not work for me?

You ask for the money back inside the window that product states and you get it. No licence key exists to revoke on any of the five, so nothing stops working while you wait. Reply to the Stripe receipt, which carries my support address and reaches me directly. If a formula or a figure in any of them turns out to be wrong, I would rather hear about it than not.

Are these subscriptions?

No. Every one of the five is a single payment and nothing renews. The refund windows are deliberately different, because each product site sets its own and I have not flattened them into one number. handsofflinks is 30 days and unconditional. toolsthatrank is 14 days in full. aiwebsitepipeline is 60 days with no reason needed, and the two sold here on ml0x.com are also 60 days, no questions asked.
